# Computer Vision: Image Features and Similarity (module notes)

Конспект модуля по признакам изображений и метрикам сходства.

## 1. Image features

Image feature (признак изображения) - характерный атрибут, извлеченный из изображения для анализа. Признаки помогают находить объекты и паттерны на изображении.

## 2. Image mass and image center

- **Mass** (масса изображения): сумма интенсивностей пикселей.
- **Center** (центр): взвешенное среднее координат пикселей, где вес - интенсивность.
- **First moment** (первый момент): среднее положение интенсивности пикселей, то есть центр.
- **Second moment** (второй момент): разброс значений пикселей вокруг центра.

Для простого среднего координат:

```
(x_c, y_c) = (Σ x_i / N, Σ y_i / N)
```

## 3. Histograms

Построение гистограммы изображения:

1. Определить диапазон значений пикселей.
2. Задать число бинов.
3. Квантовать значения интенсивности.
4. Посчитать частоту каждого бина.

Гистограмму можно представить как вектор, чтобы сравнивать изображения с помощью метрик расстояния.

## 4. Gradients

Градиент - скорость изменения интенсивности пикселей. Считается по разности соседних пикселей:

```
∂f/∂x = f(x+1, y) - f(x, y)     (горизонтальное направление)
∂f/∂y = f(x, y+1) - f(x, y)     (вертикальное направление)
```

Шаги: сначала градиентные векторы (Gx, Gy), затем для каждого из них magnitude и angle.

```
magnitude = sqrt(Gx^2 + Gy^2)
angle     = atan(Gy / Gx)
```

Пример: Gx = 3, Gy = 4, magnitude = sqrt(9 + 16) = 5.

Зачем: находить границы (edges) и переходы на изображении.

**Histogram of gradients** описывает направленные паттерны (directional patterns).

## 5. Similarity metrics

### L1 distance (Manhattan)

Сумма абсолютных разностей. В 2D форма "шара" - ромб (diamond).

Пример: точки (3, 5) и (1, 9): |3-1| + |5-9| = 2 + 4 = 6.

### L2 distance (Euclidean)

Корень из суммы квадратов разностей. В 2D форма "шара" - круг.

Пример: разности 3 и 4: sqrt(9 + 16) = 5.

Замечание: L1 >= L2, но не "всегда строго больше". Например, для (0, 0) и (3, 0) оба равны 3.

### L2 normalization

Деление вектора на его евклидову норму: `v / ||v||_2`. Евклидова норма результата равна 1. Применима к векторам и изображениям.

Пример: (3, 4) / 5 = (0.6, 0.8).

### Cosine similarity

Измеряет косинус угла между двумя ненулевыми векторами, то есть сходство направлений (а не величин).

```
cos(theta) = (a . b) / (||a|| * ||b||)
```

Нужны: скалярное произведение (dot product) и длины векторов.

Пример: a = (1, 0), b = (1, 1): a . b = 1, ||a|| = 1, ||b|| = sqrt(2), cos = 0.707.

### Cross-entropy

Измеряет различие между двумя распределениями вероятностей.

```
H(p, q) = - Σ p(i) * log(q(i))
```

Условия валидного распределения: все вероятности неотрицательны и их сумма равна 1.

Пример: p = (1, 0), q = (0.5, 0.5): H = log 2 = 0.693 (натуральный логарифм).

## Quick reference

| Метрика | Что считает |
|---|---|
| L1 | сумма абсолютных разностей |
| L2 | корень из суммы квадратов разностей |
| Cosine similarity | косинус угла между векторами |
| Cross-entropy | различие между распределениями |
